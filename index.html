Backup & Pemulihan Data

Amankan data tabungan kelas atau pulihkan data dari file cadangan

Informasi Penyimpanan Data LocalStorage:

Data aplikasi tersimpan secara **lokal di peramban (browser) perangkat ini**. Data tidak tersimpan otomatis di server/cloud. Disarankan untuk rutin mengunduh backup file JSON di bawah ini agar data aman jika peramban dibersihkan.

Cadangkan Data (Export JSON)

Unduh seluruh data siswa dan riwayat transaksi

Simpan berkas `.json` ini di komputer atau HP Anda sebagai cadangan resmi tabungan kelas 7D.

Pulihkan Data (Import JSON)

Upload file backup untuk mengembalikan data

Pilih berkas backup `.json` yang telah disimpan sebelumnya. **Perhatian:** Data saat ini akan digantikan sepenuhnya.

Zona Bahaya: Hapus Seluruh Data

Tindakan ini akan menghapus seluruh data siswa, saldo, dan transaksi dari peramban secara permanen. Pastikan Anda telah membuat cadangan!
